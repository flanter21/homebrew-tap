# Flanter21 Homebrew

## How do I install these formulae?

`brew install flanter21/homebrew/<formula>`

Or `brew tap flanter21/homebrew` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "flanter21/homebrew"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
